# Oturum Açma

Bu sayfada Veri Analizi Okulu platformuna nasıl giriş yapacağınızı öğrenin.

## Adım Adım Oturum Açma

### 1. Giriş Sayfasına Gidin

Veri Analizi Okulu ana sayfasında sağ üst köşedeki **"Giriş Yap"** butonuna tıklayın.

![Giriş yap](/img/oturum-acma/giris.png)

### 2. Bilgilerinizi Girin

Giriş formunda aşağıdaki bilgileri doldurun:

![Giriş formu](/img/oturum-acma/login.png)

| Alan                | Açıklama                                                                                         |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| **E-posta**         | Kayıt olurken kullandığınız e-posta adresi                                                       |
| **Şifre**           | Hesabınıza ait şifre                                                                             |
| **Beni Hatırla**    | Giriş bilgilerinizin kayıt izni                                                                  |
| **Şifremi Unuttum** | Daha önce sisteme giriş yapıp şifrenizi unuttuysanız tıklamanız gereken buton                    |
| **Şifre Al**        | Daha önce sisteme giriş yapmaksızın ilk defa sisteme giriş yapıyorsanız tıklamanız gereken buton |

### 3. Giriş Yapın

**"Giriş Yap"** butonuna tıklayarak hesabınıza erişin.

### 4. Farklı Giriş Seçenekleri

Eğer dilerseniz, OBS sisteminde tanımlı hesabınızın mail servis sağlayıcınız ile eşleşmesi durumunda Google, Github, Microfost ile de sisteme giriş yapmanız mümkündür.
Örnek olarak, eğer Gmail hesabınız ile sistemimizde kayıtlı iseniz Google ile giriş yap seçeneğini de tercih edebilirsiniz.

![Diğer seçenekler](/img/oturum-acma/farkli-secenekler.png)

## Sık Karşılaşılan Sorunlar

### Giriş yapamıyorum

Eğer giriş yapamıyorsanız:

- E-posta adresinizin doğru yazıldığından giriş yapmaya çalıştığınız e-posta adresinin Veri Analizi Okuluna bildirdiğiniz e-posta olduğundan emin olun.
- Caps Lock tuşunuzun kapalı olduğunu kontrol edin.
- Şifrenizi hatırlamıyorsanız [Şifremi Unuttum](/docs/vao-hesabi/sifremi-unuttum) sayfasını ziyaret edin.
- İlk defa giriş yapmaya çalışıyorsanız [Şifre Al](/docs/vao-hesabi/sifre-al) sayfasını ziyaret edin.

### Hesabım kilitlendi

Çok fazla hatalı giriş denemesi yapıldığında hesabınız geçici olarak kilitlenebilir. Bu durumda:

1. 15 dakika bekleyin.
2. Tekrar deneyin.
3. Sorun devam ederse destek ekibiyle iletişime geçin.

## İpuçları

:::tip Güvenli Giriş

- Şifrenizi kimseyle paylaşmayın
- Ortak kullanılan bilgisayarlarda "Beni Hatırla" seçeneğini işaretlemeyin
- Her oturumdan sonra çıkış yapmayı unutmayın
  :::
